5. FIVE PURPOSE-BUILT FORM EXPERIENCES
--------------------------------------------------------------------------------
All form submissions strictly adhere to the 6 Golden Rules of MYFORMCONNECT_LLM_GUIDE:
  1. Always use FormData (never JSON.stringify).
  2. Never set Content-Type header manually (browser computes multipart boundary).
  3. Always include 'Accept': 'application/json' and 'X-Requested-With': 'XMLHttpRequest'.
  4. Every input, select, and textarea has a valid name attribute.
  5. Always call e.preventDefault() in submit handlers.
  6. Every form includes a hidden honeypot spam input (_gotcha).

Form 1: Main Project Enquiry Form (src/components/EnquirySection.js)
  - Purpose: Primary conversion action for new project commissions.
  - Location: Dark section (#242421) near the page bottom.
  - Fields: Full Name, Email Address, Project Category (select), Phone (opt),
    Preferred Date (opt), Project Location (opt), Brief Description (opt), honeypot.
  - Source Attribution: "Stillframe Studio website"
  - UX: Client-side validation, loading indicator, duplicate-submission lock,
    clean confirmed success state without extraneous repeat submission buttons.

Form 2: Feature A — Consultation Scheduling Dialog (src/components/BookingModal.js)
  - Purpose: Real-time appointment scheduling for introductory calls.
  - Trigger: "Schedule a Call ↗" button in the Enquiry section.
  - Integration: Mounts #mfc-booking-widget with data-* attributes; loads booking-widget.js
    and dispatches DOMContentLoaded & turbo:render events for seamless SPA mounting.
  - Styling: Customized via public/booking-widget.css with slim 6px bronze scrollbars.
  - Accessibility: Accessible modal dialog with Escape-key and backdrop dismissal.

Form 3: Feature B — Direct Contact Form (src/components/ContactModal.js)
  - Purpose: Lightweight channel for quick studio queries without project details.
  - Trigger: "Have a general question? Contact us." links in Enquiry and Footer.
  - Fields: Full Name, Email Address, Subject, Message, honeypot.
  - UX: Clean modal dialog with confirmed success state and single Close button.

Form 4: Feature C — Exit-Intent Enquiry Popup (src/components/ExitIntentPopup.js)
  - Purpose: Non-intrusive heuristic engagement before desktop visitors leave.
  - Trigger: Desktop mouse-leave near top viewport edge (e.clientY <= 10).
  - Safeguards: Requires 8s page engagement or 20%+ scroll depth before arming.
    Suppressed while typing in form inputs, if another modal is active, or if
    previously dismissed during the session (sessionStorage). Disabled on mobile.
  - Content: "Planning something worth remembering?"
  - Fields: Name, Email, Category select, honeypot.
  - Actions: "Start an Enquiry ↗" and "Maybe Later".

Form 5: Feature D — Newsletter Subscription Form (src/components/NewsletterForm.js)
  - Purpose: Low-friction newsletter subscription.
  - Placement: Embedded in studio footer (src/components/Footer.js).
  - Copy: "Occasional notes from the studio. Selected work, creative inspiration,
    and updates from behind the lens."
  - Fields: Email Address and honeypot.
  - UX: Single-row desktop layout, confirmed success message.
